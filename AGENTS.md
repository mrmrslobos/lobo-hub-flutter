## Cursor Cloud specific instructions

### Project overview

FamilyHub (LoboHub) is a Flutter mobile/web app for family management (tasks, meals, budget, calendar, 18+ modules). Backend is Supabase (PostgreSQL, Auth, Edge Functions). See `README.md` for web deployment details.

### Flutter SDK

This project requires **Flutter >= 3.19.0** with **Dart >= 3.3.0** (see `pubspec.yaml`). The pinned dependency `shared_preferences: ^2.5.4` requires Dart SDK ^3.9.0, so use **Flutter 3.35.x+** (which ships Dart 3.9.x). Flutter is installed at `/opt/flutter/bin` and added to `PATH` via `~/.bashrc`.

### Running the app (web)

The project has no `web/` directory on `main`; generate it with `flutter create --platforms web .` before running. The app works in **local-only mode** (SharedPreferences) without Supabase credentials — no external services are required for basic development.

To run with the Supabase backend (credentials from `launch.json`):

```
flutter run -d web-server --web-port=8080 --web-hostname=0.0.0.0 \
  --dart-define=SUPABASE_URL=https://vinumlekpmddtbfkojkd.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=<key from launch.json>
```

The "Dev - no Supabase" launch config in `.vscode/launch.json` omits `--dart-define` flags entirely, running in pure local mode.

### Lint / Analyze

```
flutter analyze
```

Pre-existing warnings (38 at last count) are all info/warning level — no errors. Do not attempt to fix these unless explicitly asked.

### Tests

No `test/` directory exists in the repository (a stub `widget_test.dart` is auto-generated by `flutter create` but is not project-specific). There are no automated tests to run.

### Supabase Edge Functions

Edge Functions live under `supabase/functions/` (TypeScript/Deno). They are deployed to Supabase Cloud and are not required for local Flutter web development. Functions include: `ai-proxy`, `daily-devotional`, `weekly-digest`, `notify-family`, `calendar-sync`.

### Key gotchas

- The `README.md` references `npm install` / `npm run dev`, but there is **no `package.json`** in the repository. Those instructions apply to a separate web variant that is not included. The actual app is Flutter.
- The `web/` directory is `.gitignore`d but must exist to run `flutter run -d web-server`. Regenerate it with `flutter create --platforms web .` if missing.
- `flutter pub get` may downgrade a few transitive dependencies to match the SDK — this is expected and harmless.
